Política de privacidad

Última actualización: 4 de noviembre de 2026.

Fabrica Romadicto (la «aplicación») es una herramienta privada del canal de YouTube @Romadicto. Solo la usa el propietario del canal, en su propio canal.

Qué datos usa

Con el permiso que el propietario concede mediante Google (OAuth), la aplicación usa la API de datos de YouTube para:

  • subir las miniaturas de los vídeos del canal @Romadicto;
  • leer la lista de vídeos del canal y sus estadísticas (vistas, «me gusta», comentarios) y el número de suscriptores.

No recoge datos personales de los espectadores, no lee comentarios ni mensajes privados y no accede a otros canales.

Cómo se guardan

El permiso de acceso se guarda cifrado por Google y, en el servidor privado del propietario, en un archivo que solo él puede leer. Las estadísticas se guardan en ese mismo servidor para decidir qué temas hacer. No se venden, no se comparten con terceros y no se usan para publicidad.

Uso de los datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La aplicación también está sujeta a las Condiciones del servicio de YouTube y a la Política de privacidad de Google.

Cómo retirar el permiso

El propietario puede retirar el acceso en cualquier momento en myaccount.google.com/permissions. Al hacerlo, la aplicación deja de poder usar la API y se borran los datos guardados si se pide por correo.
